# Loop Sort Man Playable

PixiJS and TypeScript starter for the Voodoo playable ad task. The starter renders a loop on a canvas that resizes with the viewport.

## Local development

Use Node.js 20.19+ on the Node 20 line, or Node.js 22.12+.

```sh
npm ci
npm run dev
```

Run `npm run typecheck` to check TypeScript. Run `npm run build` to produce the web build in `dist/`, then `npm run preview` to serve it locally.
